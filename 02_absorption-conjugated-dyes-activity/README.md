Lesson 02: Absorption of Conjugated Dyes using the Fintie Well
=======================

The purpose of this lesson is to go through how the particle-in-a-box and the finite well model connects with UV-vis spectroscopy

## Lesson Information

#### Science Questions

1. How does the particle-in-a-box (PIB) model connect to UV-vis spectroscopy?
2. How does this connection extend to the finite well model?

#### Programming Objectives

1. Use a for loop to plot the computed UV-vis spectra.
2. Overlay the computed and experimental spectra.
3. Determine the computed $\lambda_{max}$ from the various models and spectra.
